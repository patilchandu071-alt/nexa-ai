# 🚀 NEXA AI

### Your AI Workspace

NEXA AI is an AI-powered workspace project designed to bring intelligent assistance into one place.

## ✨ Features

* AI chat assistant
* Modern web interface
* Python backend using FastAPI
* Next.js frontend
* Database integration
* Extensible architecture for future AI features

## 🛠️ Technologies Used

* Python
* FastAPI
* Next.js
* React
* TypeScript
* SQLite

## 📁 Project Structure

* `backend/` — Backend application and supporting files
* `frontend/` — Frontend web application
* `.gitignore` — Files excluded from Git

## 🎯 Project Goal

To develop a unified AI workspace that can be expanded with features such as coding assistance, writing, learning, research, and document processing.

## 👨‍💻 Developer

Created as a personal AI project.
